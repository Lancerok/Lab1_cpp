Дана сигнатура функции: `int* reverseBack(int arr[]);` *(В реализации добавлен параметр size и new_size)*
Необходимо реализовать функцию таким образом, чтобы она возвращала новый массив, в котором значения массива arr записаны задом наперед.
Пример: arr = [1, 2, 3, 4, 5] результат: [5, 4, 3, 2, 1]

### Алгоритм решения
1. Принять массив и его размер.
2. Выделить память под новый массив того же размера.
3. Запустить цикл, в котором элемент с индексом `i` нового массива получает значение элемента `size - 1 - i` старого массива.
4. Вернуть новый массив.

### Тестирование
| Входные данные (массив) | Ожидаемый результат |
|-------------------------|---------------------|
| [1, 2, 3, 4, 5]         | [5, 4, 3, 2, 1]     |
| [1, 2]                  | [2, 1]              |

## Задача 9

### Текст задачи
Дана сигнатура функции: `int* findAll(int arr[], int x);` *(В реализации добавлен параметр size и count)*
Необходимо реализовать функцию таким образом, чтобы она возвращала новый массив, в котором записаны индексы всех вхождений числа x в массив arr.
Пример: arr = [1, 2, 3, 8, 2, 2, 9], x = 2 результат: [1, 4, 5]

### Алгоритм решения
1. Принять массив, размер и искомое число `x`.
2. Первый проход: посчитать количество вхождений числа `x` в массив.
3. Выделить динамическую память под массив результатов размером равным количеству вхождений.
4. Второй проход: пройти по исходному массиву и записать индексы совпадений в новый массив.
5. Вернуть новый массив.

### Тестирование
| Входные данные (массив, x) | Ожидаемый результат |
|----------------------------|---------------------|
| [1,2,3,8,2,2,9], 2         | [1, 4, 5]           |
| [1,2,3,4,5], 6             | [] (пустой массив)  |
| [5,5,5], 5                 | [0, 1, 2]           |
